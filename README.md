# Jira MCP

Works with Jira. This plugin installs and configures it in your workspaces.

Upstream server docs: https://www.npmjs.com/package/jira-mcp

Installs from the Camillia hub as `jira-mcp-8c0a77`. On every new task the plugin posts
the ready-to-paste `mcp.servers` entry and the setup steps as a task comment.
